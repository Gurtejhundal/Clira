## Clearance checklist for each finalist
1. Web: exact phrase in quotes, common misspellings, same product category.
2. Domains: `.com`, `.app`, `.ai`, `.dev` using a registrar/WHOIS/registry, not search snippets.
3. GitHub: org/repo exact handles and near-identical names.
4. Social: YouTube handle, Instagram/X/TikTok as relevant.
5. Trademarks: national databases appropriate to markets (for example India IP India, USPTO, WIPO Global Brand Database); consider professional advice before launch.
6. Phonetic similarity: avoid names confused with existing creator-management software.
7. Read-aloud with real users; check spelling from hearing the word once.
