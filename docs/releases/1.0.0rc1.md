Clira is a local AI workspace for YouTube creators. Plan videos, prepare titles and descriptions,
review the exact video package in chat, and approve channel actions with an expressive companion.

**This is a prerelease**, with package version `1.0.0rc1`. It is intended for local, single-owner use.

## In this candidate

- Terminal-inspired web workspace with antique-gold frames, readable chat and eight accessible views.
- Faithful monochrome character with eight expressions, hover/click reactions and Full/Reduced/Off motion.
- MP4 attachment → editable package preview → owner review → approved private-upload workflow in chat.
- Creator preferences, channel-scoped memory, saved conversations, ideas, script briefs and calendars.
- Channel-bound approvals, durable jobs, hashes, receipts and recovery for uncertain account outcomes.
- Borderless black-background logo, current README, current character and website GIFs.

## Install

Requires Python 3.12+, uv, and ffmpeg/ffprobe for media validation.

For the source ZIP, extract it and run inside its folder:

```bash
uv sync --locked
./run.sh --mode demo serve
```

Open http://127.0.0.1:8765. Demo data and replies are synthetic; no Google account is required.

For an isolated console installation from the downloaded wheel:

```bash
uv tool install ./clira-1.0.0rc1-py3-none-any.whl
clira --mode demo serve
```

`SHA256SUMS.txt` covers the source ZIP, wheel and source distribution. `install-verification.json`
records separate clean-install checks for all three formats. Current instructions and account setup
are in the README and docs packaged with the source.

## Scope and verification

Publication runs Python checks, the current browser regression, chat-upload simulation, character
interactions, packaging checks and fresh installs before uploading these assets.

Real Gemini use needs explicit provider configuration; YouTube writes need the correct OAuth grant,
write enablement and exact owner approval. Uploads start private. Publishing, scheduling, replies,
thumbnail and caption uploads use separate approvals.

Video packaging uses three sampled frames; it is not full-video/audio understanding. Automatic
editing/rendering, transcription, image-model thumbnails and hosted/team access are not implemented.
The newer chat workflow has simulation coverage; live content quality and thumbnail/caption playback
remain separate validation work. No stable v1.0.0 or revenue/growth guarantee is claimed.
