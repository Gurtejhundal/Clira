Connect your real YouTube channel

Enable YouTube Data API and YouTube Analytics API in your Google Cloud project. Create a Desktop OAuth client, then run this from the project terminal:

export CLIRA_GOOGLE_CLIENT_FILE=/path/to/client.json
clira --mode live connect
clira --mode live serve

Google sign-in happens in your browser. The terminal asks you to confirm the exact channel ID. Read access is requested first.

Never paste credentials into this chat or the dashboard.

Model & account actions

The offline router handles a few fixed requests. To authorize Gemini calls with your own account, set these in your terminal and restart the app:

export CLIRA_MODEL=gemini
export GEMINI_API_KEY=…
export CLIRA_ALLOW_MODEL_CALLS=1
export CLIRA_MAX_MODEL_CALLS_DAY=50

A request cap is enforced; it is not a currency budget. Live writes remain disabled until CLIRA_ENABLE_WRITES=1, suitable OAuth scopes, and per-action approval.
