# Clira v1.0.0-rc.1 · local candidate, not published

The terminal is now the primary conversational client. Start without an account, plan a channel in a
local workspace, work with synthetic demo data, or connect your actual channel through read-only OAuth.
The local website resumes the same titled sessions, ideas, jobs and exact approvals.

Includes real thumbnail templates/imports/previews, timed SRT/VTT import/edit/preview, hashtags,
validated chapter descriptions, package hashes, and separately approved official thumbnail/caption
upload adapters. No image-model or transcription provider is configured. Original rendering remains
external/manual. No autonomous worker starts with chat or the website.

Package version uses Python's `1.0.0rc1`; the human candidate name is `v1.0.0-rc.1`.
See `docs/VERIFICATION_V1_RC.md` for reproducible checks and limitations.

Stable release blockers: owner-authorized real OAuth and sourced reads; live configured-model quality
and request cap review; one rights-cleared approved private upload with verified remote channel/privacy
and ID; separately authorized thumbnail/caption live upload and visual/timed playback checks. Additional
public/reply changes need separate approvals. Mock tests cannot satisfy these account gates.

No v1.0.0 tag, GitHub release, public posting or deployment is authorized or performed. CI only verifies;
a stable release requires all P0 evidence and a new explicit owner instruction approving publication.
