# Clira v0.1.0 · Your Creative Intelligence

The first public preview of a local YouTube operations partner. Clira brings channel context,
analytics, ideas, scripts, production handoff and approved account actions into one conversation
and a calm creator workspace.

## Included

- One bounded Python agent with typed tools, persistent channel memory and a configurable Gemini adapter.
- An eight-view responsive dashboard and useful CLI, with a no-key synthetic demo to explore immediately.
- Google desktop OAuth/PKCE, channel verification and official Data/Analytics API adapters.
- Dated performance reports, weekly comparisons, public-video research, ideas, script briefs and calendars.
- Finished MP4 import, ffprobe validation, managed copies, content hashes and owner rights/creative review.
- Exact owner approvals, private-first resumable uploads, durable jobs, retries, recovery and audit receipts.
- Separate approval paths for metadata changes, publication scheduling, publishing and comment replies.
- An animated README preview, captioned product tour, actual CLI-output walkthrough and setup documentation.

## Quick start

Requires Python 3.12+, uv, and ffmpeg/ffprobe for MP4 validation.

```bash
git clone https://github.com/Gurtejhundal/Clira.git
cd Clira
./run.sh
```

Open **http://127.0.0.1:8765/**. Default mode is synthetic demo data with a limited offline router.
For the wheel, install it into a Python environment and run `clira serve`.

## Verification and preview limits

Local verification: **61 backend tests passed**, lint/format and syntax checks passed, and the
eight-view browser flow passed at 1440px and 390px. The publishing workflow repeats backend and
browser checks before creating this release.

This is an **early MVP preview**. Live OAuth, actual Gemini behavior and real account mutations
remain unverified until an owner configures accounts and explicitly approves the relevant operations.
Development uploads and replies were simulated; videos show synthetic data. Video rendering stays
external/manual. Thumbnail upload, richer retention/cohort analysis, automatic fact verification,
complete-history pagination and hosted/team access remain future work.
